CSS : it is a stylesheet language used to change the appearance and layout of web pages
      it allows users to define colors,fonts,spacing,position and responsive layouts 
      it improves maintainability and user experience across websites 
Summary : it syles web pages,controls layout,colors,fonts and designs      

React hooks : they are functions that let users use state,features and other react capabilities inside       functional components  They simplify code and enable reusable logic through custom hooks
Summary : state and logic in functions

Zustand : it is a lightweight state management library that provides a simple global store .components can use the state they need improving performance
Summary : lightweight global state management library

React Router : It is a library for React that enables navigation between different pages or views in a single-page application it connects url to components without reloading the page 
Summary : Handles navigation and routing in React single-page applications efficiently

Global State : Global state is data that can be accessed and shared across multiple components in an application Instead of passing data through props at every level global state management allow components to read and update shared data
Summary : Shared application data accessible by multiple components without props
